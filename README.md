## Projects
### [SmartESPApp](https://github.com/TunahanDilercan/SmartESPApp)
An IoT solution built around ESP8266 firmware that reads sensors and publishes their data over WiFi, paired with an Android client for monitoring and controlling the devices.
### [Chess Arbiter AI](https://github.com/TunahanDilercan/Chess-Arbiter-AI)
A tool that reads handwritten chess scoresheets from a photograph and validates the moves against FIDE rules, built to settle threefold-repetition, fifty-move and illegal-move claims at the arbiter's table in seconds instead of minutes.
### [LMTOFF Catalog](https://github.com/TunahanDilercan/lmtoff-catalog)
A dark-themed product catalog built with Jetpack Compose, using MVVM with StateFlow, a repository abstraction, unit tests and GitHub Actions CI.
### [CTF-AutoDecryptor](https://github.com/TunahanDilercan/CTF-AutoDecryptor)
A tool for automatically identifying and deciphering encryption and encoding methods in CTF competitions.
