# Tunahan Dilercan

Mekatronik mühendisliği öğrencisiyim. Odağım **gömülü sistemler** — mikrodenetleyici
firmware'i, sensör okuma ve donanımı bir arayüzle konuşturmak. Buna ek olarak Android
tarafında da geliştirme yapıyorum; gömülü bir cihazın çoğu zaman yanında bir uygulamaya
ihtiyacı oluyor.

Buradaki projeler genelde gerçek bir ihtiyaçtan çıktı: bir cihazı telefondan izlemek,
bir turnuvada hakemlik yaparken kâğıt kontrol etmek ya da bir CTF sırasında.

## Projeler

**[SmartESPApp](https://github.com/TunahanDilercan/SmartESPApp)** — ESP8266, C++, Kotlin
ESP8266 tabanlı sensör ağı: mikrodenetleyici firmware'i verileri okuyup WiFi üzerinden
yayınlıyor, Android istemcisi bunları izleyip cihazları kontrol ediyor.

**[Chess Arbiter AI](https://github.com/TunahanDilercan/Chess-Arbiter-AI)** — Python, Computer Vision
El yazısı satranç skor kâğıtlarını fotoğraftan okuyup hamleleri FIDE kurallarına göre
denetleyen hakem aracı. Üçlü tekrar, elli hamle ve yasa dışı hamle itirazlarını inceleme
masasında dakikalar yerine saniyeler içinde çözmek için yazıldı.

**[LMTOFF Catalog](https://github.com/TunahanDilercan/lmtoff-catalog)** — Kotlin, Jetpack Compose
Koyu temalı ürün vitrini. MVVM + StateFlow, repository soyutlaması, birim testleri ve
GitHub Actions CI.

**[Chess Scoresheet Printer](https://github.com/TunahanDilercan/chess-scoresheet-printer)** — C#, .NET
Satranç turnuvaları için notasyon kâğıdı yazdırma aracı. QuestPDF ile hazır basılı
kâğıt düzenleri.

**[CTF-AutoDecryptor](https://github.com/TunahanDilercan/CTF-AutoDecryptor)** — Python
CTF yarışmalarındaki şifreleme ve kodlama yöntemlerini otomatik tanıyıp çözen araç.

**[Makalem](https://github.com/TunahanDilercan/Makalem)** — Next.js, TypeScript, Firebase
Akademik içerik platformu: makale keşfet, Markdown ile yaz ve paylaş.
